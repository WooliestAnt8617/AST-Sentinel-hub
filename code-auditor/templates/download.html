Quick Start

Drop the exe on your PATH or run it directly. No installer needed.

01

Download & Place

Download the exe and move it to a folder on your PATH (e.g. C:\tools\), or just keep it in your project folder.

02

Scan a File

cmd / powershell 
❯ ast-sentinel scan myfile.py
03

Scan a Directory

cmd / powershell 
❯ ast-sentinel scan ./my-project/ -v

All Commands

ast-sentinel --help 
❯ ast-sentinel scan path/to/file.py

❯ ast-sentinel scan ./src/ --verbose

❯ ast-sentinel scan ./src/ --json report.json

❯ ast-sentinel scan ./src/ --html report.html

❯ ast-sentinel scan ./src/ --json out.json --html out.html

❯ ast-sentinel serve --port 8080
